# Qwen3-Omni AWQ-No-TTS 四卡TP说明

## 目标

```text
一个模型计算时同时使用四张A6000
三种Agent角色不重复加载权重
尽量增加Full轨迹吞吐
```

实现方式是`tensor_parallel_size=4`，不是把三个Agent分别放到三张卡。

## 如何证明四卡都在工作

启动后执行：

```bash
bash commands/run_v1.2.2.sh omni-status
```

应看到GPU 0、1、2、3均有明显模型显存占用。

再执行：

```bash
bash commands/run_v1.2.2.sh omni-benchmark
```

报告包含每张GPU的：

```text
平均/最大显存占用
平均/最大GPU利用率
平均功耗
并发1/2/4时的请求吞吐和延迟
```

## 如何选择并发

- Debug固定并发1，不调。
- Full初始并发4。
- 若并发4失败、显存接近上限或延迟恶化，改为2。
- 若并发4稳定且GPU利用率仍低，可在`fast`档测试，但不要直接修改质量门。

## TP4与纯吞吐的区别

TP4保证每个请求跨四卡，并最大化单实例容量。若模型本身能在更少卡上运行，两个TP2副本有时能获得更高总吞吐，但它会加载两份权重、需要负载均衡，并改变实验部署条件。v1.2.2不默认采用该方案。
