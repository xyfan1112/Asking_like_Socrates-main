
# 11. 训练匹配的B1与B2

B1和B2均由full轨迹经过strict过滤后，从同一批Ref pair自动构建：

```text
B1 = 相同Direct数据 + final-only Ref pair
B2 = 相同Direct数据 + 相同Ref pair的Socratic轨迹
```

轨迹生成过程中允许部分样本失败。以下情况不阻止训练：

```text
full audit为PASS_WITH_WARNINGS
部分轨迹被strict拒绝
部分轨迹达到max rounds
部分格式修复最终fail-closed
postproc跳过少量无法转换的轨迹
```

训练使用的是最终通过strict和postproc的数据，不会把被拒绝的轨迹强行加入训练集。

但是以下检查仍然是硬性要求，不能跳过：

```text
validate-train必须PASS
validate-lf-contract必须PASS
B1/B2行数和pair关系必须匹配
训练集和验证集文件必须完整
基础模型目录必须完整
```

虽然数据文件没有变化时，人工操作可以不重复执行`validate-train`，但在一键训练脚本中建议每次都执行。该检查耗时很短，可以避免因路径、文件或配置被意外修改而浪费数小时训练时间。

## 11.1 一键训练脚本


```bash
chmod +x \
  /home/nhl/Asking_like_Socrates-main/re_scripts/main_layer/train_matched_b1_b2.sh
```

以后只需执行一个命令：

```bash
cd /home/nhl/Asking_like_Socrates-main/re_scripts

bash main_layer/train_matched_b1_b2.sh \
  "$CFG"
```

也可以不传参数，默认使用当前目录下的`settings.json`：

```bash
bash main_layer/train_matched_b1_b2.sh
```

## 11.2 B1和B2训练命令是否需要修改

原来的训练命令不需要修改：

```bash
python main_layer/run.py train-b1 \
  --settings "$CFG"
```

```bash
python main_layer/run.py train-b2 \
  --settings "$CFG"
```

一键脚本只是把以下步骤串联起来：

```text
停止Agent
验证数据
保存哈希
生成YAML
验证LLaMA-Factory合同
检查旧Adapter
训练B1
训练B2
```

它没有改变B1/B2的数据构成、学习率、epoch、batch size或LoRA参数。

## 11.3 不再直接执行`merge both`

原说明中的：

```bash
python main_layer/run.py merge \
  --settings "$CFG" \
  both
```

不适合你当前50GB数据盘。

基础模型、B1 merged和B2 merged同时存在时接近50GB，还需要Adapter、测试结果和临时写入空间，因此容易再次出现：

```text
No space left on device
```

应改为顺序合并和评测。

### 测试B0

```bash
python main_layer/run.py start-eval \
  --settings "$CFG" \
  rs_eot \
  1 \
  8010
```

```bash
python main_layer/run.py test-matrix \
  --settings "$CFG" \
```

```bash
python main_layer/run.py stop-eval \
  --settings "$CFG" \
```
